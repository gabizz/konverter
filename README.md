# 💱 Konverter

A sleek, minimalist currency converter built as a Progressive Web App (PWA). Designed with a premium dark mode aesthetic and seamless offline support.

## ✨ Features

- **Real-time Conversion**: Convert between RON, EUR, USD, and THB instantly.
- **Premium UI/UX**: Built with React and Material UI, featuring a highly polished custom dark theme, rounded modern inputs, and fluid typography that automatically scales based on number length.
- **Offline Support**: Caches exchange rates locally. Even if you lose internet connection, you can continue converting using the most recent rates.
- **PWA Ready**: Can be installed directly to your home screen on mobile or desktop for a native-like experience.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or higher

### Installation

1. Clone the repository and navigate into the folder:
   ```bash
   git clone https://github.com/gabizz/agricole-ro-site.git
   cd konverter
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## ☁️ Deployment

This project is pre-configured for instant deployment on **Vercel**. 
Simply push the repository to GitHub and import it on Vercel, or use the Vercel CLI directly from your terminal:

```bash
npx vercel
```
